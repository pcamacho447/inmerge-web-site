# Registro Central de Sesiones de Brainstorming — Inmerge

Este directorio (`docs/brainstorming/`) alberga todas las sesiones de ideación, exploración creativa y conceptualización estratégica de Inmerge.

---

## Estructura de Cada Sesión

Cada sesión de brainstorming se almacena en su propia carpeta con nomenclatura:
`docs/brainstorming/brainstorm-[tema-slug]-[YYYY-MM-DD]/`

Archivos estándar por sesión:
1. `brainstorm-intent.md` — Propósito, objetivos, postura creativa y preguntas detonantes.
2. `.memlog.md` — Registro atómico de ideas, ángulos descartados y síntesis de conceptos.
3. `brainstorm-summary.md` (o `.html`) — Resumen ejecutivo de hallazgos, conceptos ganadores y siguientes pasos hacia el backlog (`docs/tasks.md` / `SPEC.md`).
